# PROJECT ELEVEN ⚽

بازی مدیریت باشگاه فوتبال فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ.

## اجرای بازی
فایل index.html را در مرورگر باز کن یا GitHub Pages را برای مخزن فعال کن. نسخه فعال این صفحه فایل‌های زیر را بارگذاری می‌کند:
- index.html — پوسته و منوی بازی
- styles.css — طراحی واکنش‌گرا
- js/data.js — داده‌های اولیه باشگاه‌ها و بازیکنان
- js/game.js — منطق بازی و ذخیره محلی

ذخیره بازی در localStorage همان مرورگر انجام می‌شود؛ پاک‌شدن داده‌های مرورگر می‌تواند ذخیره را حذف کند.

## امکانات فعلی MVP
- داشبورد باشگاه و مدیریت فهرست بازیکنان
- باشگاه‌ها و بازیکنان خیالی، پرونده بازیکن، جست‌وجو و فیلتر
- خرید و فروش بازیکنان با بررسی بودجه و ظرفیت فهرست
- آزادسازی بازیکن با درآمد انتقالی صفر
- تاکتیک، آرایش تیم و تمرین
- لیگ رفت‌وبرگشت، شبیه‌سازی مسابقه و جدول امتیازات
- پیش‌بینی رایگان؛ برای ثبت پیش‌بینی نباید پول یا سکه‌ای کسر شود
- آمار و تاریخچه پایه
- ذخیره محلی و شروع مجدد بازی

## محدودیت‌ها
این نسخه MVP محلی است، نه بازی آنلاین چندنفره. حساب کاربری، پایگاه داده ابری، همگام‌سازی بین دستگاه‌ها، اجرای خودکار مسابقات هنگام بسته بودن مرورگر، چت، PvP، بازار آنلاین و اعتبارسنجی سمت سرور هنوز فعال نیستند. شبیه‌سازی مسابقه و اقتصاد ساده‌سازی شده‌اند.

## مسیر توسعه
1. تثبیت MVP و آزمون سقف فهرست، خرید، فروش، آزادسازی، مسابقات و ذخیره
2. تکمیل قراردادها، قرضی، آکادمی، استعدادیابی، اقتصاد و کادر فنی
3. توسعه موتور مسابقه، جام‌ها و آمار دقیق‌تر
4. افزودن بک‌اند و پایگاه داده برای ذخیره امن آنلاین
5. امکانات اجتماعی و چندنفره پس از ایجاد زیرساخت سروری
6. آماده‌سازی Android/Capacitor

نسخه قدیمی تک‌فایلی در archive/index-legacy.html نگهداری شده است. فایل app.js در ریشه از نسخه جایگزین قبلی است و توسط index.html فعلی بارگذاری نمی‌شود.
