# PROJECT ELEVEN ⚽
بازی مدیریت باشگاه فوتبال، فارسی و راست‌چین، با طراحی واکنش‌گرا برای موبایل و دسکتاپ.

## اجرای بازی
فایل index.html را در مرورگر باز کنید یا شاخه phase-1-playable-mvp را با GitHub Pages منتشر کنید. این نسخه به نصب پکیج یا API key نیاز ندارد. ذخیره بازی در localStorage همان مرورگر انجام می‌شود؛ پاک‌شدن داده‌های مرورگر می‌تواند ذخیره را حذف کند.

## امکانات MVP
- داشبورد باشگاه، بودجه، ظرفیت فهرست و جدول لیگ
- ۸ باشگاه خیالی و فهرست شروع دقیقاً ۱۵ بازیکنی برای هر باشگاه
- کارت بازیکن، جست‌وجو، فیلتر پست و مرتب‌سازی
- خرید از بازار با بررسی بودجه و سقف فهرست
- فروش بازیکن و دریافت مبلغ فروش
- آزادسازی بازیکن بدون دریافت هیچ درآمدی
- آرایش و ذهنیت تیم، انتخاب ۱۱ بازیکن اصلی
- تمرین تیمی و فردی، آمادگی و مصدومیت ساده
- لیگ رفت‌وبرگشت ۸ تیمی: ۱۴ بازی برای هر تیم و ۵۶ بازی در مجموع
- شبیه‌سازی نتیجه مسابقه و ثبت امتیاز و آمار لیگ
- پیش‌بینی کاملاً رایگان و جلوگیری از ثبت تکراری برای هر مسابقه
- تاریخچه رویدادها و آمار پایه

## محدودیت‌های صریح
این نسخه MVP آفلاین است، نه محصول آنلاین چندنفره. حساب کاربری، دیتابیس ابری، اجرای خودکار مسابقات وقتی مرورگر بسته است، چت، PvP، پرداخت و همگام‌سازی بین دستگاه‌ها پیاده‌سازی نشده‌اند. شبیه‌سازی مسابقه ساده است و هنوز موتور رویدادمحور کامل، VAR یا اقتصاد پیشرفته ندارد. پیش‌بینی هیچ سکه یا پول واقعی مصرف نمی‌کند و جایزه نقدی ندارد.

## مراحل توسعه بعدی
1. آزمون و تثبیت MVP و جلوگیری از ناسازگاری داده‌ها
2. قراردادها، قرضی، آکادمی، استعدادیابی، اقتصاد، استادیوم و کادر فنی
3. موتور مسابقه رویدادمحور، تقویم و پردازش یکتای نتایج
4. بک‌اند و دیتابیس برای ذخیره امن آنلاین، سپس امکانات اجتماعی و PvP
5. آماده‌سازی Android/Capacitor

## ساختار پروژه
- index.html: پوسته و بارگذاری فایل‌ها
- styles.css: طراحی واکنش‌گرا
- js/data.js: داده‌های خیالی شروع
- js/game.js: منطق بازی و ذخیره محلی
- archive/index-legacy.html: نسخه قبلی برای مراجعه

شاخه phase-1-playable-mvp حاوی توسعه جدید است. شاخه main عمداً دست‌نخورده نگه داشته شده تا نسخه قبلی از بین نرود.
