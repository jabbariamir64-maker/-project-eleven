# PROJECT ELEVEN ⚽

شبیه‌ساز مدیریت باشگاه فوتبال با رابط فارسی و راست‌چین. این مخزن اکنون یک نسخه قابل‌بازی اولیه (Phase 1 MVP) دارد که با HTML/CSS/JavaScript خالص اجرا می‌شود و به ابزار ساخت یا سرور نیاز ندارد.

## اجرای بازی
- فایل `index.html` را در مرورگر باز کنید، یا مخزن را با GitHub Pages منتشر کنید.
- پیشرفت بازی در `localStorage` همان مرورگر ذخیره می‌شود. برای ادامه بازی از همان دستگاه و مرورگر استفاده کنید.
- از دکمه ذخیره بالای صفحه می‌توانید ذخیره‌سازی را دستی هم انجام دهید.
- برای شروع از ابتدا، گزینه «شروع بازی جدید» پایین صفحه را بزنید. این کار ذخیره فعلی را پاک می‌کند.

## قابلیت‌های پیاده‌سازی‌شده در این نسخه
- رابط موبایل‌محور، فارسی و RTL
- داشبورد باشگاه، بودجه، قدرت تیم و وضعیت فهرست
- هشت باشگاه و فهرست آغازین ۱۵ بازیکن برای هر باشگاه
- پروفایل بازیکن، جست‌وجو، فیلتر پست و مرتب‌سازی
- خرید و فروش بازیکن با بررسی بودجه و ظرفیت
- آزادسازی بازیکن بدون هیچ درآمد انتقالی
- جلوگیری از عبور فهرست از ظرفیت و حفظ حداقل ۱۱ بازیکن برای هر باشگاه
- تمرین آمادگی، تمرین فنی، ریکاوری و تاکتیک‌های پایه
- لیگ ۸ تیمی رفت‌وبرگشت؛ ۱۴ مسابقه برای هر تیم و ۵۶ مسابقه کل
- شبیه‌سازی مسابقه، ثبت نتایج، گل‌ها و جدول رده‌بندی
- اقتصاد پایه، ارتقای ورزشگاه، آمار و تاریخچه قهرمانی
- پیشرفت محلی و نگهداری داده‌ها پس از بستن و بازکردن مرورگر

## نکته‌های مهم و محدودیت‌های فعلی
این نسخه یک بازی محلی قابل‌بازی است، نه بازی آنلاین چندنفره. هنوز ورود کاربران، پایگاه‌داده سروری، همگام‌سازی بین دستگاه‌ها، مسابقات خودکار در زمان آفلاین، پیام‌رسانی، لیگ‌های PvP، موتور مسابقه پیشرفته، قراردادهای قابل مذاکره، آکادمی کامل و بسته اندروید پیاده‌سازی نشده‌اند. هیچ پرداخت واقعی یا خرید پولی در بازی وجود ندارد.

## ساختار فایل‌ها
- `index.html`: صفحه اصلی بازی
- `styles.css`: طراحی واکنش‌گرا و رابط کاربری
- `app.js`: منطق بازی و ذخیره محلی
- `archive/index-legacy.html`: نسخه قبلی آرشیوشده پیش از بازسازی

## مرحله بعدی توسعه
1. تست‌های خودکار قوانین فهرست، انتقال‌ها و سازگاری جدول لیگ
2. بهبود موتور مسابقه و آمار رویدادهای واقعی‌تر
3. قراردادها، مصدومیت‌ها، استعدادیابی و آکادمی
4. انتقال ذخیره به پایگاه‌داده و API سروری برای حالت آنلاین
5. آماده‌سازی برای Android/Capacitor
