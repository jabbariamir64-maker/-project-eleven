# PROJECT ELEVEN ⚽

بازی مدیریت باشگاه فوتبال فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ.

## اجرای بازی
فایل index.html را در مرورگر باز کن یا GitHub Pages را برای مخزن فعال کن. نسخه فعال از این فایل‌ها استفاده می‌کند:
- index.html — پوسته و منوی بازی
- styles.css — طراحی واکنش‌گرا
- js/data.js — داده‌های اولیه باشگاه‌ها و بازیکنان
- js/game.js — منطق بازی و ذخیره محلی

پیشرفت در localStorage همان مرورگر ذخیره می‌شود؛ پاک‌کردن داده‌های مرورگر می‌تواند ذخیره را حذف کند.

## امکانات فعلی MVP
- داشبورد باشگاه و مدیریت فهرست بازیکنان
- ۸ باشگاه خیالی با فهرست اولیه ۱۵ نفره
- پرونده بازیکن، جست‌وجو، فیلتر و مرتب‌سازی
- خرید از بازار با بررسی بودجه و ظرفیت فهرست
- فروش بازیکن با درآمد و آزادسازی بازیکن با درآمد انتقالی صفر
- تاکتیک و ضدتاکتیک: مالکیت، ضدحمله، بازی کناری، پاس مستقیم، پرس و دفاع عمیق
- موتور مسابقه مبتنی بر ویژگی‌های فنی و بدنی، تناسب پست، آمادگی و تعامل تاکتیک‌ها
- امتیاز کلی بازیکن در رابط معمول بازی مخفی است؛ ویژگی‌های تخصصی و بدنی جداگانه نمایش داده می‌شوند
- قد، وزن، پتانسیل رشد و ویژگی‌های اختصاصی بازیکنان؛ امتیاز کلی با وزن‌دهی متناسب با پست محاسبه می‌شود
- تمرین اختصاصی برای دریبل، سرعت، قدرت، استقامت، شوت، پاس، بازی هوایی و مهارت‌های دیگر؛ محدودیت هفتگی و مصرف آمادگی
- گزارش مسابقه با رویدادهای ثبت‌شده، مالکیت توپ، شوت‌ها و برآورد موقعیت‌ها
- تاکتیک، آرایش تیم، تمرین و ریکاوری
- لیگ رفت‌وبرگشت ۸ تیمی: ۱۴ بازی برای هر تیم و ۵۶ بازی در کل
- با انتخاب بازی بعدی، تمام مسابقات همان هفته شبیه‌سازی می‌شوند تا جدول لیگ هماهنگ بماند
- پیش‌بینی رایگان؛ ثبت پیش‌بینی هیچ پول یا سکه‌ای کم نمی‌کند
- جایزه درون‌بازی برای پیش‌بینی دقیق، فقط یک بار برای هر پیش‌بینی
- شروع فصل جدید پس از تکمیل مسابقات و ثبت قهرمان فصل قبل
- آمار و تاریخچه پایه و ذخیره محلی

## محدودیت‌ها
این نسخه MVP محلی است، نه بازی آنلاین چندنفره. حساب کاربری، پایگاه داده ابری، همگام‌سازی بین دستگاه‌ها، اجرای خودکار مسابقات هنگام بسته بودن مرورگر، چت، PvP، بازار آنلاین و اعتبارسنجی سمت سرور هنوز فعال نیستند. این موتور هنوز نسخه اولیه و آفلاین است؛ اعداد و تعاملات تاکتیکی باید با شبیه‌سازی‌های آماری گسترده‌تر متعادل شوند.

## مسیر توسعه
1. تثبیت MVP و آزمون سقف فهرست، خرید، فروش، آزادسازی، مسابقات و ذخیره
2. قراردادها، قرضی، آکادمی، استعدادیابی، اقتصاد و کادر فنی
3. توسعه موتور مسابقه، جام‌ها و آمار دقیق‌تر
4. افزودن بک‌اند و پایگاه داده برای ذخیره امن آنلاین
5. امکانات اجتماعی و چندنفره پس از ایجاد زیرساخت سروری
6. آماده‌سازی Android/Capacitor
