# PROJECT ELEVEN ⚽

بازی مدیریت باشگاه فوتبال فارسی و راست‌چین، با رابط واکنش‌گرا برای موبایل و دسکتاپ.

## اجرای نسخه فعلی
فایل index.html را در مرورگر باز کن یا از GitHub Pages برای انتشار نسخه وب استفاده کن. فایل‌های فعال این نسخه:
- index.html — پوسته برنامه
- styles.css — طراحی واکنش‌گرا
- app.js — منطق بازی و ذخیره محلی

پیشرفت در localStorage همان مرورگر ذخیره می‌شود. پاک کردن داده‌های مرورگر می‌تواند ذخیره را حذف کند.

## امکانات پیاده‌سازی‌شده
- داشبورد باشگاه، بودجه، ظرفیت فهرست و جدول لیگ
- ۸ باشگاه خیالی با دقیقاً ۱۵ بازیکن شروع برای هر باشگاه
- پرونده بازیکن، جست‌وجو، فیلتر پست و مرتب‌سازی
- خرید از بازار با بررسی بودجه، ظرفیت و حداقل بازیکنان باشگاه فروشنده
- فروش بازیکن به باشگاه دیگر با درآمد انتقال
- آزادسازی بازیکن با درآمد انتقالی صفر و بدون هزینه آزادسازی
- آرایش تیم، نمایش ۱۱ بازیکن برتر، سبک بازی، شدت پرس و سرعت بازی
- تمرین آمادگی، تمرین فنی و ریکاوری
- لیگ رفت‌وبرگشت ۸ تیمی: ۱۴ بازی برای هر تیم و ۵۶ بازی در مجموع
- شبیه‌سازی مسابقات و ثبت نتیجه، گل‌ها، امتیاز و جدول لیگ
- اقتصاد پایه، بودجه، دستمزد و ارتقای ورزشگاه
- آمار فصل، گلزنان و تاریخچه قهرمانی‌ها
- ذخیره محلی خودکار و شروع مجدد بازی با تأیید

## محدودیت‌های فعلی
این نسخه MVP محلی است، نه بازی آنلاین چندنفره. حساب کاربری، پایگاه داده ابری، همگام‌سازی بین دستگاه‌ها، اجرای خودکار مسابقات در زمان بسته بودن مرورگر، چت، PvP، نقل‌وانتقالات آنلاین و موتور مسابقه پیشرفته هنوز پیاده‌سازی نشده‌اند. رابط پیش‌بینی رایگان نیز هنوز در نسخه فعال کامل نشده است؛ در زمان اضافه شدن، ورود به پیش‌بینی باید بدون کسر سکه یا پول باشد.

## مراحل توسعه بعدی
1. تثبیت MVP و آزمون خرید، فروش، آزادسازی، جدول و ذخیره‌سازی
2. تکمیل پیش‌بینی رایگان و جوایز یک‌باره
3. قراردادها، قرضی، آکادمی، استعدادیابی و کادر فنی
4. موتور مسابقه رویدادمحور و جام‌ها
5. بک‌اند و دیتابیس برای ذخیره امن آنلاین، سپس امکانات اجتماعی و PvP
6. آماده‌سازی Android/Capacitor
