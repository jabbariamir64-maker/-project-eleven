# PROJECT ELEVEN ⚽

شبیه‌ساز مدیریت باشگاه فوتبال فارسی و راست‌چین، با طراحی سازگار با موبایل.

## اجرا
فایل index.html را باز کن یا GitHub Pages را در تنظیمات مخزن فعال کن. فایل‌های styles.css و game.js باید در کنار index.html باشند.

## امکانات این نسخه
- لیگ ۸ تیمی رفت‌وبرگشت (۱۴ بازی برای هر تیم)
- شبیه‌سازی مسابقه و جدول برد/مساوی/باخت، گل زده/خورده و امتیاز
- ۱۵ بازیکن شروع برای هر باشگاه و سقف ثبت بازیکن
- پروفایل بازیکن، جست‌وجو و مرتب‌سازی
- خرید، فروش با درآمد و آزادسازی بدون درآمد
- تمرین، رشد محدود بازیکنان جوان، آمادگی، مصدومیت ساده و ریکاوری
- ارتقای ورزشگاه و ظرفیت تیم، تغییر نام باشگاه
- پیش‌بینی کاملاً رایگان؛ ثبت آن هیچ پول یا سکه‌ای کم نمی‌کند
- ذخیره خودکار محلی، خروجی JSON و بازیابی ذخیره

## قوانین کلیدی
- ظرفیت پیش‌فرض هر باشگاه ۱۵ بازیکن است و خرید در ظرفیت کامل مسدود می‌شود.
- فروش بازیکن درآمد دارد؛ آزادسازی بازیکن درآمد انتقالی ندارد.
- پیش‌بینی مسابقات رایگان است.
- پیشرفت در localStorage همین مرورگر ذخیره می‌شود.

## محدودیت‌های شفاف
این نسخه MVP محلی است. حساب کاربری، پایگاه داده سروری، چندنفره آنلاین/PvP، اخبار زنده، موتور مسابقه پیشرفته و اجرای خودکار مسابقات در زمان آفلاین هنوز پیاده‌سازی نشده‌اند. برای آنلاین شدن واقعی به بک‌اند امن، پایگاه داده و اعتبارسنجی سمت سرور نیاز داریم.

## مسیر توسعه
۱. تست و تثبیت MVP
۲. قراردادها، وام، استعدادیابی، آکادمی و کادر فنی
۳. رویدادهای مسابقه و جام‌ها
۴. بک‌اند، حساب کاربری، ذخیره آنلاین و چندنفره
۵. آماده‌سازی Android/Capacitor

## تست‌های دستی
- خرید در ظرفیت کامل باید مسدود شود
- فروش باید بودجه را افزایش دهد
- آزادسازی نباید درآمدی ایجاد کند
- پیش‌بینی نباید هزینه داشته باشد
- اجرای مسابقه باید جدول را به‌روزرسانی کند
- خروجی گرفتن و بازیابی ذخیره
